# Security Policy

## Supported versions

The latest version on the default branch is the supported version.

## Reporting a vulnerability

Please do not publish sensitive security details in a public issue.
Open a private security report through GitHub if the repository has that feature enabled, or contact the repository maintainer privately.

Please include:

- affected component/file
- reproduction steps
- impact
- suggested mitigation, if known

This project is primarily a local prototype. Do not upload real private images or secrets to a public issue.
